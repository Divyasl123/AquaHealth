# AquaHealth 💧

### IoT-Based Water Quality Monitoring and Analysis System

AquaHealth is an IoT-based project designed to monitor water quality using sensors and display the collected readings through a web dashboard.

## Features
- Real-time TDS monitoring
- Temperature monitoring
- Water quality status indication
- Buzzer alert when the configured TDS threshold is exceeded
- Live web dashboard
- Data visualization and monitoring

## Hardware Components
- ESP32 Development Board
- TDS Sensor
- DS18B20 Temperature Sensor
- Buzzer

## Technologies Used
- Arduino IDE
- Embedded C++ 
- HTML
- CSS
- JavaScript
- ESP32 Wi-Fi

## Dashboard
The web dashboard displays sensor readings and water-quality information in an easy-to-understand format.
